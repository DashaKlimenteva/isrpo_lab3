# File Time Tracker Plugin

**Автор:** Климентьева Дарья Антоновна(502446), M3109

## Описание плагина

File Time Tracker - это плагин для IntelliJ IDEA, который отслеживает время работы с открытыми файлами в редакторе.

## Возможности

### Основные функции:
- ✅ Автоматическое отслеживание времени работы с файлами
- ✅ Старт отслеживания при первом открытии файла
- ✅ Расчет общего времени работы с файлом
- ✅ Удобное форматирование времени (часы, минуты, секунды)
- ✅ Поддержка одновременного отслеживания нескольких файлов

### Дополнительные возможности:
- 📊 Информационные уведомления о начале отслеживания
- ⏱️ Точный расчет длительности работы
- 🗂️ Уникальная идентификация файлов по полному пути
- 💾 Временное хранение данных в течение сессии

## Использование
1. Откройте файл в редакторе IntelliJ IDEA
2. Перейдите в меню **Tools → "Show File Open Time"**
3. Плагин покажет:
    - Для нового файла: время начала отслеживания
    - Для уже открытого файла: общее время работы

## Установка
1. Соберите плагин с помощью Gradle
2. Установите через **File → Settings → Plugins → Install Plugin from Disk**
3. Перезапустите IDE
